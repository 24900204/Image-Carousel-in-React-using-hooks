# Image-Carousel-in-React-using-hooks


## Aim

To design and develop a responsive Image Carousel using React Hooks that allows users to view multiple images with automatic sliding, previous/next navigation, and dot-based slide selection.

##  Algorithm
Start the React application.
Create an array containing the images and their corresponding titles and descriptions.
Import and use the React Hooks useState and useEffect.
Use useState to maintain the current image/slide index.
Display the image corresponding to the current index.
Create Previous and Next buttons to change the current image.
Create navigation dots and allow the user to select any image directly.
Use useEffect with a timer to automatically change the image after a fixed interval.
Apply CSS to create a responsive and attractive carousel layout.
Display the user's Name and Register Number in the footer.
Execute and test the application in the browser.
Stop.
